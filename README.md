# 色碼電阻計算

這個 Python 專案包含一個終端機色碼電阻計算器，可根據四環或五環電阻的顏色計算阻值及誤差。

## 環境需求

- Python 3.12 或更新版本。
- 計算器只使用 Python 標準函式庫，不需另外安裝套件。

## 執行方式

在專案目錄執行：

```powershell
python .\02-色碼電阻計算.py
```

依照提示選擇 4 或 5 個色環，從距離電阻一端較近的色環開始，輸入各顏色對應的數字。每個步驟會顯示該色環可使用的編號；輸入無效時可重新輸入。

| 編號 | 顏色 | 編號 | 顏色 |
| --- | --- | --- | --- |
| 0 | 黑 | 6 | 藍 |
| 1 | 棕 | 7 | 紫 |
| 2 | 紅 | 8 | 灰 |
| 3 | 橙 | 9 | 白 |
| 4 | 黃 | 10 | 金 |
| 5 | 綠 | 11 | 銀 |

例如四環電阻「黃、紫、紅、金」，依序輸入 `4`（環數）、`4`、`7`、`2`、`10`，結果為 `4.7 kΩ ±5%`。

四環使用前兩環作為有效數字；五環使用前三環。接著輸入倍率環和誤差環，程式會依阻值顯示 Ω、kΩ 或 MΩ。第一環不接受黑色；各色環的可用顏色依提示為準。目前不支援三環、六環或零歐姆電阻的特殊表示。
